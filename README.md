# Campus Fest Manager
# Project Overview
Campus Fest Manager is a Salesforce-based solution designed to streamline the end-to-end management of college fests and events, including Technical, Cultural, and Sports categories.

The application provides a centralized platform for managing event information, participant registrations, event scheduling, registration fee tracking, and email communication.
